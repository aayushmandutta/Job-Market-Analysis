# Job Market Analysis

An end-to-end **Data Analytics project** analyzing **742 job records and 42 features** to identify job-market trends, salary patterns, hiring demand, technical skills, and education-related insights.

## Key Analysis

* State-wise job distribution and salary trends
* Top industries and companies hiring
* Most in-demand job titles and technical skills
* Salary comparison across roles and locations
* Education vs. salary analysis
* Company age, salary, rating, and revenue analysis

## Data Processing

* Extracted data from **MySQL** using SQL
* Cleaned and transformed data using **Python and Pandas**
* Handled missing and invalid values
* Performed feature engineering on salary, revenue, and location data

## Dashboard

Built an interactive **Power BI dashboard** to visualize job distribution, salary trends, industry demand, and skill requirements.

## Technologies

**Python | Pandas | NumPy | SQL | MySQL | Power BI | Matplotlib | Seaborn**
